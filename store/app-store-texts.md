## Privacidade do app (questionário)
Em **Privacidade do app**:
1. **URL da política de privacidade:** `https://crssolution.github.io/monta-pdf/privacy.html`
2. "Você ou seus parceiros coletam dados deste app?" → **Não, nós não coletamos dados deste app**
3. Clique em **Publicar**.

Por quê: para a Apple, "coletar" é enviar dados para fora do aparelho, para o desenvolvedor ou parceiros. O app não tem servidor nem SDKs de terceiros: nome, e-mail e ID da Apple ficam só no aparelho, e os documentos ficam no iCloud privado do próprio usuário, sem acesso do desenvolvedor. A loja mostra o selo "Dados não coletados".

## Informações para a revisão da Apple
- **Login obrigatório?** Marque que o app usa **Sign in with Apple** (não precisa de conta de demonstração).
- **Notas para o revisor** (copie):
```
Monta PDF uses Sign in with Apple only, so no demo account is needed: please sign in with any Apple ID.
The scanner uses the camera (VisionKit), so please test it on a physical device. Imports work with photos, PDF and Word (.docx/.doc) files from the Files app.
Documents are stored with SwiftData + CloudKit in the user's private iCloud database. Account deletion is available in Account > Delete Account.
```
